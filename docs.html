1. 简介

MoeZ（萌Z，前身为 Moeblog / Moe Home）是一套原生 PHP、无框架依赖的轻量二次元博客建站系统。核心能力覆盖：

  • 内容：Markdown / UEditorPlus 双编辑器、分栏预览、自动保存、自动标签、阅读密码、独立页面
  • 社区：多用户角色（站长/作者/订阅者）、评论、投稿（审核流）、友链自助申请
  • 商业：积分 + 金币双货币、积分商城、金币充值（扫码/网关/人工）、授权码商品自动签发
  • 分发：HMAC 站点授权、主题/插件在线安装与更新、自动更新源端点
  • 陪伴：AI 看板娘（OpenAI 兼容接口、联网搜索、多轮记忆、配额监控）
  • 运维：在线更新与备份回滚、页面缓存、Redis 缓存、SEO 推送记录、蜘蛛管理
  • 工程：2.2.30 工程化 —— 统一上传服务、主题路径适配层、config.sample、nginx / Caddy / Docker 部署配置、面板一键部署元数据
本文所有函数名均可在 includes/ 对应文件中按名检索，均为源码真实存在的行为。

4. 核心 API

4.1 数据库

q($sql, $args = [])          // 执行写操作（INSERT/UPDATE/DELETE）
row($sql, $args)             // 取一行（关联数组或 null）
rows($sql, $args, $key = '') // 取多行
one($sql, $args)             // 取单个值
last_id()                    // 最近插入 ID
moe_table($name)             // 加前缀表名；moe_pt_table() 同理

4.2 设置与缓存

setting($key, $default)  /  setting_set($key, $val)
cache_get / cache_set / cache_del / cache_flush
moe_remember($key, $ttl, $cb)      // 记忆化（Redis 优先回落文件）
moe_content_changed()              // 内容变更统一失效入口（页面缓存 + 记忆化）
moe_cache_test($host,$port,$auth,$db)  // 后台 Redis 连通性测试

4.3 正文渲染与邮件

render_content($content, $format)      // format=markdown 走自研渲染；html 原样输出（仅 @[login] 锁生效）
excerpt_text($content, $len = 160)     // 摘要截取
moe_mail_ready()                       // SMTP 是否已配置
moe_mail_send($to, $subject, $html)    // 返回 ['ok'=>bool,'msg'=>string]
moe_mail_template($title, $lines, $btnText, $btnUrl)  // 统一邮件模板
所有通知类邮件务必用 moe_mail_ready() 守卫：未配置 SMTP 时静默跳过，不阻塞主流程。

5. 用户中心与投稿

5.1 架构

用户中心是核心渲染而非主题模板：moe_user_center_page($mode, $seg)（includes/user.php）按 ?a= 分发视图，外壳 moe_uc_shell($title,$sub,$body,$u) 统一输出头部、页签、样式与页脚。入口 /user。

moe_uc_tabs($u, $a, $uc)         // 一级分组导航 + 二级页签（moe_uc_tab_match() 做选中匹配）
moe_uc_shell(...)                // 页面外壳；body 含 ctForm 时自动附加投稿 JS
moe_uc_view_home / profile / comments / posts / author / recharge ...
moe_uc_css_extra()               // 附加样式（含主题适配变量）

5.2 主题配色自动适配（2.2.22）

moe_uc_theme_vars()    // 解析当前模板 assets/style.css 的 :root（--pink/--violet/--bg/--card...）
moe_uc_css_root()      // 输出 --uc-* 变量（color-mix 生成深浅变体）
moe_uc_css_themify($css) // 把用户中心 CSS 里写死的 hex 替换为 var(--uc-x, 原色) —— 换主题即换配色

5.3 投稿系统（2.2.22）

  • 视图 moe_uc_view_contribute($u)：封面/附件上传、正文编辑器跟随站长设置（moe_editor_mode()：markdown 或 ueditor）、勾选「同时上架资源」可定价
  • 保存 moe_uc_contribute_save($uid, $in)：文章写入 status='pending'、src='contribute'；关联商品写入 pt_goods.status='off'（post_id 关联）；发送「投稿成功」邮件（moe_mail_ready 守卫）
  • 前台绝不渲染 pending 文章 —— 投稿正文可能是未审核 HTML，render_content 的 html 分支不过滤
  • 审核在后台文章管理：「待审核投稿」筛选 + ✅通过 / ↩退回；通过 = status → published、商品 status → on、moe_uc_contribute_notify($title,$authorId,true) 发「已通过」邮件；退回转草稿并发提醒。编辑待审文章改为「公开发布」同样视为通过
  • 会员上传接口 api/upload.php / api/ueditor-server.php：登录 + X-CSRF-Token，图片 ≤10MB、附件受 upload_max_mb 限制，每人每天 40 次

5.4 友链自助申请（2.2.22）

moe_uc_view_friendlink($u) + moe_uc_friend_apply($name,$url,$contact)：按 host 去重、moe_check_backlink($url) 检测回链，已加本站链接自动通过否则转待审，结果邮件通知。

5.5 我的授权码页签

moe_uc_auth_can($uid) 判定资格（管理员 / 已购买程序或「授权码」类商品），页签按资格显示；签发写入 content/updates/user-auth-codes.json，主站侧同步 auth-sites.json。

7. 授权系统

moe_auth_code_generate($domain, $days, $secret)  // 签名格式 MH-<时间戳>-<随机>-<hmac20>
moe_auth_code_verify($code, $secret)             // 本地 HMAC 校验，不依赖外部回调
moe_auth_check() / moe_auth_cached()             // 终端站校验（带缓存）
moe_auth_hub_url() / moe_auth_site_domain()      // 授权站与域名规整
moe_auth_zip_apply / incremental_apply           // 授权站分发更新包的增量应用
content/updates/user-auth-codes.json             // 用户自助签发档案
content/updates/auth-sites.json                  // 主站侧授权站点档案

主站即授权站兼更新源；程序 / 主题 / 插件分别独立检测。用户中心支持邮箱验证码自助签发（2.2.22 起也可由商城授权码商品自动签发）。

8. 更新系统

8.1 更新源

后台仪表盘「⚙ 更新源」保存 settings.update_check_url（保存即强制重查，绕过 10 分钟结果缓存）。

moe_update_feed_url()        // 读取更新源地址
moe_update_feed_valid($url)  // SSRF 防护：仅公网 http(s)、禁账号密码、禁内网；不跟随重定向（裸域名 301 会失败，务必填 www 直链）
moe_update_fetch($url)       // 拉取 JSON，要求包含 version 字段
moe_update_check()           // 本地版本 vs 源版本（version_compare），结果缓存进 settings.update_check_cache

8.2 自动更新源端点 update-feed.php（2.2.23）

部署在分发站根目录，让站长「丢 zip 即发版」，不再手动维护 version.json：

优先级：update/feed.json（手动兜底） > update/ 目录里版本号最高的 zip > 站点根 version.json

发版流程：把 moe-home-v2.2.30.zip 上传到 update/ 目录即可（moe-home 为更新源识别关键字，改名会导致发版识别不到）
可选：update/notes.txt（每行一条更新说明，# 开头为注释）

防误报：文件名含 moe-home 才识别任意数字版本；其余文件必须 v 前缀（backup-2026-11-13.zip 不会误判）
下载地址自动生成为 zip 绝对直链（配合 6.3 下载代理，用户点击即自动下载）

8.3 在线更新执行

moe_update_download($url)      // 下载更新包；version.json 的 download 支持蓝奏云/微云分享链接（可带 ?pwd= 或「密码:xxx」提取码，自动解析真实直链）
moe_update_apply_zip($file)    // 应用更新：排除用户数据文件（config.php/install.lock/content/uploads/cache），校验后覆盖
moe_update_rollback()          // 备份回滚
moe_update_workspace()         // 临时工作目录（升级包解压、备份）

9.3 前台挂载（任意主题三步接入）

版娘组件默认由 moez-companion 插件自动挂载（首次访问自动启用，站长停用后不再自动打开，8 套主题通用，CSS/JS/立绘走 ?moez_cp_asset= 代理）；自研主题也可按下方协议手动接入——在 footer 里输出一个带 data-* 属性的容器即可：

<div class="my-companion" id="my-companion"
     data-api="<?php echo e(base_url() . 'chat.php'); ?>"
     data-token="<?php echo e(function_exists('csrf_token') ? csrf_token() : ''); ?>"
     data-name="<?php echo e(function_exists('moe_chat_name') ? moe_chat_name() : '小星'); ?>"
     data-greet="你好呀～我是本站看板娘，有事随时问我">
  <div class="my-cp-panel">…气泡面板 / 输入框 / 历史列表（样式自定）…</div>
  <img class="my-cp-avatar" src="<?php echo e(theme_url('assets/mascot.png')); ?>" alt="">
</div>

配套 JS（随主题 assets 携带）只做三件事：

  1. POST data-api，body 带 q，请求头带 X-CSRF-Token: data-token
  2. 渲染返回 JSON：{ reply, actions?, chips? }（chips 为 moe_chat_chips() 推荐话题按钮）
  3. 「重新开始」按钮调 moe_chat_hist_clear() 对应的清空动作（或刷新会话）
不想自己写 JS 的主题启用插件即可。配置优先级：后台调试台 moez_cp_* → 当前主题 themeopt_{主题}_* → 内置默认（mascot_name 名字、mascot_side 左右、voice_* TTS 音色语调）。fomalhaut 自带挂载块会自动让出（function_exists 判断），不会同页出现两套版娘。

13. 安全规范

  • CSRF：csrf_token() / csrf_field()（POST _token）/ csrf_verify() / csrf_ajax()（header X-CSRF-Token）——所有写操作必须过验证
  • 上传：统一上传服务（includes/upload.php，2.2.30 工程）——扩展名白名单 + getimagesize 图片校验 + fileinfo 真实 MIME 校验（扩展缺失自动降级）+ 大小受 upload_max_mb；按 image/video/audio/file 月度分目录；文件名净化并保留原文件名主干（重名追加 6 位随机尾缀）
  • SSRF：moe_update_feed_valid() 只放行公网 http(s)，拉取不跟随重定向
  • 投稿隔离：pending 状态绝不经 render_content 输出到前台（未审核 HTML 不过滤）
  • 支付：充值回调验签，人工通道二次确认；pt_orders 状态机防重复入账
  • 授权：HMAC 签名本地校验，密钥仅存授权站；终端站不可伪造
